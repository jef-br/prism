### T-5050 · `multiple-products` is never written false, so one phenotype is unreachable
**Status:** Ready | **Profile:** P1-feature-worker
**Split from:** [[T-4000]] item 1, 2026-08-05 — second of the 11 per-analyzer calibration questions to
get its own ticket, after [[T-5000]].

`Analyzer_MultipleProducts` writes `multiple-products` **only when YOLO returns more than one object**.
It never writes `false`. **Cause:** the analyzer treats "not multiple" as absence of evidence rather
than as a measurement. **Effect:** the feature reads `UNKNOWN` on every single-product image, and
`PhenotypeRuleSet` treats `UNKNOWN` as satisfying nothing (`PhenotypeRuleSet.cs:125`).
**Consequence:** `on-model-with-accessories`, which hard-requires `multiple-products = true`, can never
be assigned on any image where the detector is right, and every rule that would want to *exclude*
multi-product shots has no signal to read. Measured by [[T-4970]]: UNKNOWN on **86/86** SPACINI29
images.

**The second half is the reason this is not a one-line change.** The analyzer's own doc records it:
a pair of shoes is two YOLO detections and would read `multiple-products = true`, which is wrong — it
is one product. So flipping the analyzer to write `false` on a single detection without handling the
same-class-pair case just moves the error to footwear. Needs either product-type-aware handling or a
same-class-pair exemption, and the two interact with `Analyzer_HasHuman` (a person plus a product is
also two detections).

**Data is in-repo, no new dataset needed.** Footwear pairs: `2426834-7558_*` (3 shots) and the
`F-MODE-GO-…-SANDALS-…` set in `BE tests`. Single-product bags: `OMB-E166-BV_*`, `OMB-E180-BV_*`,
`OMB-E181-CVW_*`. On-model single-product: all 86 SPACINI29 images.

**Acceptance:** `multiple-products` carries a KNOWN value on every image where YOLO ran; a shoe pair
reads `false`; a genuine accessories shot reads `true`; state the confusion matrix on the images
listed above; and say explicitly whether a person counts toward the product count.

`jb/src/core/config/analyzer_Config.json`, `jb/src/core/config/ImageRoles.json` (read-only reference).
