## daily-brief.md

- File: `daily-brief.md` at repo root. Generated by the scheduled claude.ai routine (or `/daily-brief` on demand) — do NOT regenerate it per session.
- Overwrite, never append. Heading is always exactly `# Daily Brief` — never add a date to it.
- Sections: `##### Changed`, `##### Todo updates`, `##### Next steps`. Compare against the previous brief so Changed reports real deltas.
- Commit and push directly to `main`, no feature branch, no approval. Stage only daily-brief.md.
- Commit message: `Daily brief - dd/mm/yy` (e.g. `Daily brief - 11/07/26`).
